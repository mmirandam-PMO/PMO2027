# 📊 Tablero de Control Operativo y Roadmap · PMO 2027

¡Bienvenido! Este repositorio aloja el **Reporte Ejecutivo de la PMO** convertido en una aplicación web interactiva de alto rendimiento. Diseñado con una estructura limpia para el monitoreo ágil y estratégico de los programas corporativos.

## 🚀 Características
*   **Buscador en Tiempo Real:** Filtra instantáneamente proyectos o encargados desde la barra superior de la vista de tablero.
*   **Vista de Roadmap Integrada:** Línea de tiempo interactiva estilo Gantt para visualizar la duración de los proyectos por meses.
*   **Alineación Anti-Desfases:** Organizado mediante columnas lógicas fijas que impiden huecos visuales.
*   **Insumo Independiente:** La base de datos se gestiona enteramente desde `data.js`, eliminando la necesidad de programar para realizar cambios.

## 📂 Archivos del Repositorio
1.  `index.html`: Estructura ósea del tablero y contenedores base.
2.  `styles.css`: Identidad visual, gradientes avanzados, fuentes y diseño dinámico del roadmap.
3.  `data.js`: Base informativa centralizada del portafolio.
4.  `app.js`: Cerebro y motor de renderizado dinámico del buscador.
5.  `roadmap.html`: Interfaz independiente con el Timeline ejecutivo del proyecto.
6.  `README.md`: Documentación oficial del proyecto.
